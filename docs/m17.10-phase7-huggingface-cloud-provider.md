# RYVEN 3.0 — M17.10 Phase 7: Secure Hugging Face Cloud Provider Integration

## Overview

Milestone 17.10 Phase 7 integrates Hugging Face Cloud Inference into RYVEN 3.0 as an optional, explicitly authorized expert AI provider, while preserving local Ollama + Qwen 2.5 7B as the authoritative default engine.

All model inference continues strictly through the established architecture:
`AI Consumer → UnifiedAIProvider → ModelRouter → ModelSecurityGateway → HuggingFaceAdapter → HuggingFaceRemoteProvider`

---

## 1. Architectural Architecture & Core Invariants

```mermaid
graph TD
    Consumer[AI Consumer\nAssistant / Planner / Code] --> Unified[UnifiedAIProvider]
    Unified --> Router[ModelRouter]
    Router --> Gateway[ModelSecurityGateway\nPrivacy Mode & Replay Protection]
    Gateway -->|Approved & Authorized| HFAdapter[HuggingFaceAdapter]
    Gateway -->|LOCAL_ONLY or Unconfirmed| Deny[SecurityViolationError\nFail-Closed, Zero Egress]
    HFAdapter --> HFRemote[HuggingFaceRemoteProvider\nBounded Retries, Timeouts, Auth Header]
    HFRemote --> HFCloud[Hugging Face Inference API\n/chat/completions (REST / SSE Stream)]
    HFCloud --> Resp[Normalized AIResponse / AIStreamChunk\nAIUsage Preserved, Redacted Logs]
```

### Invariants Enforced:
1. **Ollama Local Default**: Qwen 2.5 7B through local Ollama remains the default for all routine tasks, assistant chats, and planning.
2. **Opt-In & Disabled by Default**: Hugging Face remote inference is disabled by default (`allow_remote_ai_inference = False`, `hf-remote-qwen-coder.enabled = False`).
3. **No Direct Egress**: Assistant, planner, vision, and frontend cannot make direct Hugging Face calls; all requests route through `UnifiedAIProvider` and `ModelSecurityGateway`.
4. **Privacy Modes**:
   - `LOCAL_ONLY`: Strictly blocks all Hugging Face remote requests with `SecurityViolationError`.
   - `PRIVACY_FIRST`: Requires valid, unexpired, un-replayed confirmation tokens bound to the specific provider and model.
5. **No Token Exposure**: Hugging Face API keys (`HF_API_KEY`, `HUGGINGFACE_API_KEY`, `HF_TOKEN`) are never logged, never exposed to the frontend, never returned in health checks or telemetry, and redacted from error messages.
6. **Bounded Retries with Backoff**: Transient errors (HTTP 429, 502, 503, 504, connection drops) are retried with exponential backoff up to `max_retries = 2`. Non-retryable errors (400, 401, 403, 404, security violations, cancellations) fail immediately with zero retries.
7. **Genuine SSE Streaming**: SSE streaming over `/chat/completions` parses incremental deltas through `StreamChunkSanitizer`. Local provider streaming requests reject cleanly with `ProviderUnavailableError` without generating fake chunks.
8. **Token Usage Metadata**: `prompt_tokens`, `completion_tokens`, and `total_tokens` are extracted from the provider response and preserved in `AIResponse.usage` as typed `AIUsage` objects.

## 2. Configuration Reference

Hugging Face provider settings are configured via environment variables or `.env`:

| Variable | Default Value | Description |
| :--- | :--- | :--- |
| `ALLOW_REMOTE_AI_INFERENCE` | `false` | Global gate for remote cloud inference. Must be explicitly set to `true` to permit cloud execution. |
| `HF_API_KEY` | `None` | Hugging Face User Access Token (Bearer). Alternatively reads `HUGGINGFACE_API_KEY` or `HF_TOKEN`. |
| `HF_BASE_URL` | `https://api-inference.huggingface.co/v1` | Base URL for Hugging Face Inference API / router. |
| `HF_MODEL` | `Qwen/Qwen2.5-Coder-32B-Instruct` | Default approved Hugging Face model identifier. |
| `HF_TIMEOUT_SECONDS` | `60.0` | Connection and response read timeout in seconds. |

## 3. Normalized Error Hierarchy

| Upstream Condition | Normalized Exception | Retry Policy | Circuit Breaker Impact |
| :--- | :--- | :--- | :--- |
| Missing / Blank API Key | `AuthenticationError` | No retry | None |
| HTTP 401 / 403 (Invalid token / forbidden) | `AuthenticationError` | No retry | None |
| HTTP 429 (Rate limited) | `RateLimitError` | Bounded retry (backoff / `Retry-After`) | Trips breaker if retries exhausted |
| HTTP 500 / 502 / 503 / 504 | `ProviderUnavailableError` | Bounded retry (backoff) | Trips breaker if retries exhausted |
| Connection drop / DNS fail | `ProviderUnavailableError` | Bounded retry (backoff) | Trips breaker if retries exhausted |
| Request / Read Timeout | `ProviderTimeoutError` | No retry (mutation safety) | Trips breaker |
| Security Policy / Privacy denial | `SecurityViolationError` | No retry (fail-closed) | None (no fallback permitted) |
| Request Cancellation | `asyncio.CancelledError` | No retry | None |
