# RYVEN 3.0 — M17.10 Phase 2: Multi-Model Streaming & Response Chunking

## Overview
Milestone 17.10 Phase 2 implements genuine incremental streaming, response chunking, and boundary sanitization for RYVEN 3.0. It defines provider-neutral stream event types (`AIStreamChunk`, `StreamEventType`), an explicit streaming interface on `ProviderAdapter`, incremental transport streaming for `OllamaAdapter`, and boundary-leakage protection (`StreamChunkSanitizer`).

---

## 1. Normalized Streaming Contract (`contracts.py`)
- **`AIStreamChunk`**:
  - `event_type`: Lifecycle state indicator (`start`, `delta`, `done`, `error`).
  - `delta`: Incremental sanitized text token delta.
  - `model_id`: Model identifier used for inference.
  - `provider`: Provider enum or string identifier.
  - `finish_reason`: Completion reason (`stop`, `length`) on `done`.
  - `usage`: `AIUsage` token accounting metrics on `done`.
  - `latency_ms`: Round-trip execution latency in milliseconds.
  - `error`: Normalized `AIProviderError` on `error`.
  - `metadata`: Sanitized dictionary carrying provider metadata.
  - Helper properties: `is_start`, `is_delta`, `is_done`, `is_error`, `model`.
  - Safe `__repr__`: Truncates/masks delta preview, hides raw payloads.

- **`ProviderAdapter.stream(request: AIRequest) -> AsyncIterator[AIStreamChunk]`**:
  - Asynchronous generator contract yielding `AIStreamChunk` instances.
  - Non-streaming `generate()` remains 100% backward-compatible.

---

## 2. Stream Safety & Chunk-Boundary Sanitization (`StreamChunkSanitizer`)
Treats generated model text as untrusted:
1. **Model-Internal `<think>` Stripping**:
   - Strips internal `<think>...</think>` tokens emitted by reasoning models (e.g., DeepSeek, Qwen).
   - Handles `<think>` and `</think>` tags split across arbitrary chunk boundaries (e.g. `<th` in chunk 1, `ink>` in chunk 2).
   - Discards unclosed thinking blocks on stream completion.
2. **Chunk-Boundary Secret Redaction**:
   - Holds back a minimum bounded lookback tail (up to 128 chars) if trailing text matches or starts matching sensitive triggers (`Bearer`, `xai-`, `hf_`, `sk-`, `confirmation_token=`, `api_key=`, `token=`).
   - Prevents credential leakage before the pattern finishes across chunk boundaries.
   - Flushes and sanitizes remaining tail on stream completion.
3. **Execution Safety Invariants**:
   - Streaming text never executes shell commands or privileged actions.
   - Streamed chunks never bypass `SafetyGuard`, `CapabilityPermissionManager`, or `ConfirmationManager`.
   - Partial chunks are never written to durable semantic memory or episodic memory.

## 3. Provider Capabilities & Transports
- **Ollama (`OllamaAdapter` & `OllamaProvider`)**:
  - Genuine incremental streaming via `/api/chat` with `stream=True`.
  - Consumes newline-delimited JSON chunks line-by-line via HTTP transport (`httpx.AsyncClient.stream()`).
  - Emits `START` event, stream `DELTA` events with sanitization, and final `DONE` event with `AIUsage`.
  - Maps transport timeouts and connection errors to `ProviderTimeoutError` or `ProviderUnavailableError`.
  - Clean resource release on consumer cancellation (`asyncio.CancelledError`).
- **Grok (`GrokAdapter`)**:
  - Existing transport only supports non-streaming HTTP completion.
  - `stream()` raises `ProviderUnavailableError` (and yields an `ERROR` event).
  - No fake streaming (never splits full responses into artificial chunks).
- **Hugging Face (`HuggingFaceAdapter`)**:
  - Existing local stub and remote transport do not have streaming protocols.
  - `stream()` raises `ProviderUnavailableError` (and yields an `ERROR` event).
  - No fake streaming.
